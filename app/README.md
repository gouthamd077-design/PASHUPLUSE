# PASHU PULSE — Frontend (React + Vite PWA)

This folder contains the client-side Progressive Web Application (PWA).

- Built with React, Vite, and Tailwind CSS.
- Uses IndexedDB for complete offline capability (animals, timeline, offline triage, sync queue).
- Bilingual (English + Hindi/regional).

Will be scaffolded and implemented starting in Stage 8 as outlined in the Master Build Plan.
